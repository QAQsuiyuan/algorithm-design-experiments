一、排序问题

================================================================
1.1  冒泡排序 (Bubble Sort)
----------------------------------------------------------------
思想：重复扫描待排序序列，依次比较相邻元素，若逆序则交换，
      每轮将当前未排序部分的最大元素"冒泡"到末尾。

伪代码：

  BUBBLE-SORT(A[1..n])
      for i = 1 to n - 1 do
          swapped = false
          for j = 1 to n - i do
              if A[j] > A[j + 1] then
                  swap(A[j], A[j + 1])
                  swapped = true
              end if
          end for
          if swapped = false then
              break          // 本轮未发生交换，已有序
          end if
      end for

时间复杂度：最好 O(n)　平均 O(n²)　最坏 O(n²)
空间复杂度：O(1)（原地排序）
稳定排序：是

================================================================
1.2  合并排序 (Merge Sort)
----------------------------------------------------------------
思想：将待排序序列递归地平分两半，分别排序后再合并，
      体现了"分治法"的核心思想：分解 → 求解 → 合并。

伪代码：

  MERGE-SORT(A[1..n])
      if n <= 1 then
          return A
      end if
      mid = floor(n / 2)
      left  = MERGE-SORT(A[1..mid])
      right = MERGE-SORT(A[mid+1..n])
      return MERGE(left, right)


  MERGE(L[1..nL], R[1..nR])
      令 i = 1, j = 1, result 为空列表
      while i <= nL and j <= nR do
          if L[i] <= R[j] then
              result.append(L[i])
              i = i + 1
          else
              result.append(R[j])
              j = j + 1
          end if
      end while
      将 L[i..nL] 剩余元素追加到 result
      将 R[j..nR] 剩余元素追加到 result
      return result

时间复杂度：Θ(n log n)（最好=平均=最坏）
空间复杂度：O(n)（需要辅助数组）
稳定排序：是

================================================================
1.3  快速排序 (Quick Sort)
----------------------------------------------------------------
思想：选取一个基准元素 (pivot)，通过一趟划分将序列分为
      左右两部分——左侧均 ≤ pivot，右侧均 ≥ pivot，
      再递归地对左右子序列分别排序。

伪代码：

  QUICK-SORT(A, lo, hi)
      if lo >= hi then
          return
      end if
      p = PARTITION(A, lo, hi)
      QUICK-SORT(A, lo, p - 1)
      QUICK-SORT(A, p + 1, hi)


  PARTITION(A, lo, hi)
      pivot = A[hi]                // 选取末尾元素为基准
      i = lo - 1                   // i 指向左侧区域尾部
      for j = lo to hi - 1 do
          if A[j] <= pivot then
              i = i + 1
              swap(A[i], A[j])
          end if
      end for
      swap(A[i + 1], A[hi])        // 将 pivot 放到正确位置
      return i + 1                 // 返回 pivot 最终位置

时间复杂度：最好 O(n log n)　平均 O(n log n)　最坏 O(n²)
空间复杂度：O(log n)（递归栈深度）
稳定排序：否

二、0-1 背包问题
----------------------------------------------------------------
问题描述：给定 n 个物品，物品 i 的重量为 wᵢ，价值为 vᵢ，
          背包容量为 C。每种物品只能选 0 个或 1 个。
          求使得装入背包物品总价值最大的选择方案。

================================================================
2.1  蛮力法 (Brute Force)
----------------------------------------------------------------
思想：枚举所有 2ⁿ 种选择方案，逐一判断重量是否超限，
      在合法方案中取价值最大者。

伪代码：

  KNAPSACK-BRUTE-FORCE(w[1..n], v[1..n], C)
      best_value  = -∞
      best_select = [0, 0, ..., 0]

      for mask = 0 to 2ⁿ - 1 do      // 每个 mask 代表一种选择方案(二进制位)
          cur_weight = 0
          cur_value  = 0
          feasible   = true

          for i = 1 to n do
              if bit(mask, i) = 1 then        // 第 i 位为 1 表示选中
                  cur_weight = cur_weight + w[i]
                  cur_value  = cur_value  + v[i]
                  if cur_weight > C then
                      feasible = false
                      break
                  end if
              end if
          end for

          if feasible and cur_value > best_value then
              best_value  = cur_value
              best_select = mask 对应的选择向量
          end if
      end for

      return best_value, best_select

时间复杂度：O(n · 2ⁿ)
空间复杂度：O(n)
特点：保证全局最优，但仅适用于 n ≤ 25 左右的小规模问题。

================================================================
2.2  动态规划法 (Dynamic Programming)
----------------------------------------------------------------
思想：定义 dp[j] = 容量为 j 时能获得的最大价值。
      对每个物品 i，从后往前更新 dp 数组（避免同一物品重复使用）。
      状态转移方程：dp[j] = max(dp[j], dp[j - wᵢ] + vᵢ)。

伪代码：

  KNAPSACK-DP(w[1..n], v[1..n], C)
      // 初始化
      令 dp[0..C] 为全 0 数组
      令 choice[1..n][0..C] 为全 0 数组   // 用于回溯选择方案(可选)

      // 动态规划
      for i = 1 to n do
          for j = C downto w[i] do        // 逆序遍历, 保证每件物品只用一次
              if dp[j - w[i]] + v[i] > dp[j] then
                  dp[j] = dp[j - w[i]] + v[i]
                  choice[i][j] = 1        // 标记物品 i 被选中
              end if
          end for
      end for

      max_value = dp[C]

      // 回溯找出选择了哪些物品(可选步骤)
      j = C
      selected = [0, 0, ..., 0]
      for i = n downto 1 do
          if choice[i][j] = 1 then
              selected[i] = 1
              j = j - w[i]
          end if
      end for

      return max_value, selected

时间复杂度：O(n · C)
空间复杂度：O(C)（使用一维滚动数组） 或 O(n · C)（需要回溯时）
特点：保证全局最优，但时间与容量 C 成正比，C 过大时效率降低。

================================================================
2.3  贪心法 (Greedy)
----------------------------------------------------------------
思想：贪心准则——按"单位重量价值（vᵢ / wᵢ）"从大到小排序，
      优先装入性价比最高的物品，直到背包满。

伪代码：

  KNAPSACK-GREEDY(w[1..n], v[1..n], C)
      // 按价值密度降序排列
      items[1..n] = 每个物品的 (id, w, v, v/w)
      按 items[i].ratio 降序排序 items

      cur_weight = 0
      cur_value  = 0
      selected   = [0, 0, ..., 0]

      for i = 1 to n do
          idx = items[i].id
          if cur_weight + w[idx] <= C then
              selected[idx] = 1
              cur_weight     = cur_weight + w[idx]
              cur_value      = cur_value  + v[idx]
          end if
      end for

      return cur_value, selected

时间复杂度：O(n log n)（排序开销）
空间复杂度：O(n)
特点：速度快但不保证全局最优。对于 0-1 背包问题，贪心法给出的
      是近似解而非精确最优解（但对分数背包问题是最优的）。

================================================================
2.4  回溯法 (Backtracking)
----------------------------------------------------------------
思想：按深度优先策略搜索解空间树。搜索到某节点时先检查是否可能
      包含更优解（借助限界函数/上界函数剪枝），若不可能是更优解，
      则逐层回溯，不再搜索以该节点为根的子树。

      上界函数：对剩余物品按"分数背包"方式计算价值上界。
      排序策略：物品按价值密度降序排列，提升剪枝效果。

伪代码：

  KNAPSACK-BACKTRACK(w[1..n], v[1..n], C)
      // 预处理：按价值密度降序排序物品（便于计算上界）
      items[1..n] = 每个物品的 (原序编号, w, v, v/w)
      按 items[i].ratio 降序排序 items

      best_value = 0
      best_sel   = [0, 0, ..., 0]
      cur_sel    = [0, 0, ..., 0]

      // 限界函数：计算当前状态下的价值上界
      // (剩余物品按分数背包方式贪心填入)
      BOUND(k, cur_w, cur_v):
          bound_v = cur_v
          remain  = C - cur_w
          for i = k to n do
              if items[i].w <= remain then
                  bound_v = bound_v + items[i].v
                  remain  = remain  - items[i].w
              else
                  bound_v = bound_v + items[i].v * (remain / items[i].w)
                  break
              end if
          end for
          return bound_v

      // 递归回溯核心
      BACKTRACK(k, cur_w, cur_v):
          if k > n then                          // 到达叶节点
              if cur_v > best_value then
                  best_value = cur_v
                  best_sel   = cur_sel 的拷贝
              end if
              return
          end if

          // 情况一：选择物品 k（左子树）
          if cur_w + items[k].w <= C then
              new_w = cur_w + items[k].w
              new_v = cur_v + items[k].v
              if BOUND(k + 1, new_w, new_v) > best_value then
                  cur_sel[k] = 1
                  BACKTRACK(k + 1, new_w, new_v)
              end if
          end if

          // 情况二：不选物品 k（右子树）
          cur_sel[k] = 0
          if BOUND(k + 1, cur_w, cur_v) > best_value then
              BACKTRACK(k + 1, cur_w, cur_v)
          end if

      // 启动搜索
      BACKTRACK(1, 0, 0)

      // 结果映射回原始物品顺序
      return best_value, best_sel

时间复杂度：最坏 O(2ⁿ)，但上界函数剪枝使实际搜索远小于理论值
空间复杂度：O(n)（递归栈深度）
特点：保证全局最优。在物品价值密度差异大、背包容量适中时剪枝效果极好；
      物品价值密度相近或容量很小时搜索空间大，效率急剧下降。
